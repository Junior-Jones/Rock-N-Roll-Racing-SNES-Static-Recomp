AUTHORITY AND METHOD
V05C production authority is a lossless projection of frozen V04C source proof only. The exact target ROM is used as an external byte-identity/source input. Gameplay, gameplay traces, natural routes, Mesen traces and oracle observations contribute zero production contexts, zero successor targets and zero generated bodies.
The generator groups exact production keys by ((PBR<<16)|PC)>>10 into 18 deterministic 1 KiB address shards. Each shard switches only on the exact PBR:PC:E:M:X key. A shard miss returns JS_EXEC_NOT_MINE; the top dispatcher converts the final miss into JS_STOP_UNKNOWN_CONTEXT. No generic runtime 65816 decode path exists.

PROJECTION COUNTS
V04C admitted 2,258 unique PBR:PC:E:M:X keys at 2,158 unique PBR:PC addresses. V05C emits exactly the same 2,258 keys and covers exactly the same 4,803 source-proved physical ROM bytes.
2,238 keys have a fixed native instruction body plus a source-specific finite successor guard. Exactly 20 keys have no V04-proved outgoing edge and are emitted only as named non-execution boundaries.
The V04 edge union becomes exactly 2,488 unique source-key/to-key successor relations. Every live body checks its resulting PBR:PC:E:M:X against only that source key's finite V04C set.

FAIL-CLOSED BOUNDARIES
The 57 V04 fail-closed evidence rows collapse to 32 exact production keys. Twenty are boundary-only production keys. Twelve are mixed return keys that have at least one proved return plus an older/unproved return path: their RTS/RTL semantics execute, but a live return outside the source-specific proved set stops as JS_STOP_UNPROVED_RETURN.
Boundary-only keys stop before partial speculative execution. The named classes are JS_STOP_UNPROVED_DYNAMIC_TARGET, JS_STOP_UNPROVED_INTERRUPT_REENTRY and JS_STOP_UNPROVED_RETURN.

NATIVE CPU SEMANTICS
runtime/v05c_static_cpu.c provides fixed semantic/address/stack helpers called by generated bodies. It is not an opcode decoder and has no mnemonic/opcode dispatch table. Live memory effects use a generic byte read/write callback seam solely as the future V06C machine interface. A missing callback stops as JS_STOP_BUS_UNAVAILABLE; V05C does not hide a generic SNES bus implementation in the CPU layer.
The fixed semantics include native/emulation E/M/X normalization, hidden accumulator B preservation in 8-bit M mode, zero-high index behavior, binary and decimal ADC/SBC, NZVC behavior, direct/absolute/long/stack-relative addressing used by this target, direct-indirect pointer rules, fixed call/return stack behavior, REP/SEP/XCE/PLP width transitions and the complete reached instruction subset.
16-bit memory RMW reads low/high then writes the result high byte first and low byte second, matching the certified V02C access contract. Emulation-mode 8-bit memory RMW emits the required dummy write of the original byte before the final write.
Relative branches are generated with explicit signed integer constants rather than host implementation-defined signed-byte casts.
