PATH AND STACK PROOF
V04C path state includes PBR:PC:E:M:X plus DBR, direct page, finite register/flag producer facts, source origin and an exact symbolic top-of-hardware-stack window. The future production dispatch identity remains PBR:PC:E:M:X; extra path state is analysis proof, not a runtime decoder.
The stack model is byte-accurate. A 16-bit push followed by an 8-bit pull consumes only the low byte and leaves the high byte, matching 65C816 behavior. This closes the native mixed-width PHP/PHX/PHY/PHA restore pattern at 80:F9E9 and 80:FA2E without guessing status bits.
V04C also proves the Rock n' Roll Racing bulk stack-cleanup idiom at 80:83C5-83CD: TSX; TXA; CLC; ADC #$000A; TAX; TXS advances S by exactly ten source-proved bytes, exposing the exact older RET16 frame before RTS. The prior false unmatched-return boundary at 80:83CD is therefore closed.
To keep interprocedural proof finite, the analyser retains an exact 20-byte top-of-stack window. Older caller bytes are deliberately forgotten. Any pull or return crossing that unknown base fails closed; no older continuation is guessed.

The 29 return rows occur only after the finite exact stack-history window has been exhausted; each has zero remaining source-modelled stack bytes. They fail closed instead of guessing an older caller.
